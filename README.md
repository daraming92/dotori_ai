# 도톨이 AI

내 블로그의 주제와 어조를 바탕으로 키워드 발굴부터 자료 준비, 초안 작성, 최종 검수까지 이어주는 Windows용 프로그램입니다.

v1.0 설치 파일과 버전별 변경 안내는 아래 공식 배포 페이지에서 제공합니다.

## 다운로드와 시작

[공식 다운로드](https://github.com/daraming92/dotori_ai/releases/latest)에서 `Source code.zip`이 아니라 `DotoliAI-버전-setup.exe` 형식의 설치 파일을 선택하세요. 공개 저장소의 설치 파일 다운로드에는 GitHub 로그인이 필요하지 않습니다. 제작자가 제공하는 정확한 파일명과 SHA256을 대조하세요. 출처나 무결성을 확인할 수 없는 파일을 실행하지 마세요.

Windows 10/11 x64용입니다. 개발 PC의 격리 설치·업데이트 시험과 별도 노트북에서의 사용자 정상 작동 보고를 확보했습니다. 모든 Windows 환경의 작동을 보증하지 않으며 개발 도구가 없는 깨끗한 가상 PC 시험은 별도로 완료하지 않았습니다. macOS용 설치 파일은 제공하지 않습니다.

1. 설치 후 연결 설정에서 본인의 AI 계정과 네이버 API 연결을 확인합니다.
2. 본인 블로그를 등록하고 내 블로그 스타일을 진단합니다.
3. 키워드 탐색·트렌드 관측·블로그 벤치마킹으로 키워드를 발굴하고 보관합니다.
4. 사용할 키워드를 선택해 글 작성 준비 자료를 확인하고 승인합니다.
5. 초안을 작성하고 최종 검수 후 직접 확인한 글을 복사하거나 내보냅니다.

작성 원칙은 프로그램에 포함됩니다. 별도 PDF나 다른 사람의 작업 DB를 받아 넣지 마세요. 블로그 자동 발행과 이미지 생성은 지원하지 않습니다.

## 비용과 한계

프로그램은 무료입니다. 외부 AI 계정·검색 API의 이용 조건, 요금과 호출 한도는 별도입니다. 프로그램이 무료라는 것이 모든 외부 서비스까지 무료라는 뜻은 아닙니다.

키워드 확보 수, 검색 상위노출, 방문자 수, 수익을 보장하지 않습니다. AI의 분석·초안·검수에는 오류가 있을 수 있으며 게시 전 사실과 출처를 직접 확인해야 합니다.

## 업데이트와 데이터

버전은 v1.0, v1.1, v1.2처럼 표시합니다. 업데이트는 약 1~2주 간격을 목표로 하며, 일정은 변경될 수 있습니다.

앱 실행 시 공식 채널에서 새 버전을 확인합니다. 자동 업데이트 설정을 한 번 켜면 작업이 끝난 뒤 저장·백업하고 검증된 새 버전을 설치·재실행합니다. 자동 업데이트를 끄고 직접 확인·설치할 수도 있습니다. 네트워크·서명·만료·저장 검사에 실패하면 설치하지 않고 기존 버전을 유지합니다.

업데이트 파일은 공개 검증키로 서명과 무결성을 확인합니다. 이것은 Windows의 공인 제작자 코드 서명과 별개이며, PC 보안 정책에 따라 경고가 표시되거나 실행이 제한될 수 있습니다. 보안 기능을 끄거나 출처가 불명확한 파일을 실행하지 마세요.

사용자 작업은 프로그램 설치 폴더와 분리해 저장됩니다. 업데이트 및 일반적인 앱 제거로 작업 데이터를 지우지 않습니다. 데이터·로그 화면에서 저장 위치와 백업·복구 기능을 확인하세요. 최신 DB를 이전 버전 앱으로 열지 마세요.

공개 전 시험용 v1.0을 이미 설치했다면 최종 v1.0 설치본으로 직접 교체해야 합니다. 같은 버전 이름의 다른 파일은 자동 업데이트 대상으로 취급하지 않습니다. 공개 후에는 v1.1처럼 버전을 올린 정식 업데이트를 제공합니다.

## 오픈소스 구성요소

설치 폴더의 `THIRD_PARTY`에 사용 라이브러리의 저작권·라이선스와 교체 안내를 제공합니다. 배포 시 설치 파일과 함께 대응 소스 자산 7개 및 `SOURCE_DOWNLOADS.txt`를 별도로 제공합니다. 일반 사용자는 소스 파일을 모두 다운로드할 필요가 없습니다.

Microsoft 런타임 이용 조건은 설치 화면과 `THIRD_PARTY_TERMS_V1.txt`에서 확인할 수 있습니다. 일반 사용자가 Visual Studio를 설치할 필요는 없습니다. 해당 조건은 LGPL 등 다른 구성요소의 라이선스가 부여하는 권리를 제한하지 않습니다.

이것은 사용 라이브러리에 관한 안내이며 도톨이 자체 개발 소스·PDF·개인자료를 공개한다는 뜻은 아닙니다. 원본 소스 모음에는 실행 파일에 연결되지 않은 개발·시험 구성요소도 있습니다. 라이브러리별 실제 권리와 조건은 원문 라이선스를 확인하세요.

## 문의 시 주의

AI 연결 문제는 연결 설정에서 선택 모델과 ‘AI 연결 다시 확인’을 확인하세요. 새 연결 모듈이 필요하다는 안내는 프로그램 업데이트로 해결해야 하며, 지원 모델이 없는 경우에는 ‘지원 모델 확인’ 후 직접 선택할 수 있습니다. 모델을 바꾸면 이후 생성 결과가 달라질 수 있습니다. 로그인·사용 한도·네트워크 문제는 업데이트만으로 해결되지 않습니다. 작업 전에 짧은 실제 연결 시험을 하므로 계정 사용량이 소량 소비됩니다.

중단된 작업은 복구 안내의 ‘저장된 작업으로 돌아가기’에서 확인하고 해당 화면의 재개·이어쓰기 버튼을 사용하세요. 업데이트 후 분석이나 새 초안 작성을 무조건 자동 실행하지는 않습니다.

문제 발생 시 앱 버전, 사용한 기능, 오류 코드, 재현 순서를 기록하세요. API 키·인증 파일·작업 DB·개인 백업·블로그 원문은 공개 이슈나 댓글에 올리지 마세요.
